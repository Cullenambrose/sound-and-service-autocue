# BOOTH BUDDY icon

Original AppKit artwork generated by `generate_icon.swift`. No external assets, fonts, competitor branding or Metal are used. The five level bars use BOOTH BUDDY's teal/green palette.

Regenerate into a temporary directory, then package:

```sh
swift Branding/generate_icon.swift /tmp/BoothBuddy.iconset
iconutil -c icns /tmp/BoothBuddy.iconset -o Branding/BoothBuddy.icns
```

The common backend packaging function copies the icon into both Xcode and standalone app bundles; `Info.plist` selects it.
