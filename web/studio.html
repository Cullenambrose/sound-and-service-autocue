Supported filter fields
q, artist, genre, bpm_min, bpm_max, energy_min, energy_max (0..1), clean_only, never_played, scope_ids, sort (title/bpm/energy/last_played), limit (1..1000). Combine typed filters with bounded nested all/any arrays (up to 8 children each, 3 nested levels, 32 total rule nodes). Example: {"all":[{"genre":"House"},{"any":[{"bpm_min":120},{"clean_only":true}]}]}. Numeric bounds exclude unknown values. Clean means tagged clean, not verified audible content.

        Reviewed play windows and transition evidence
        
    By default this is evidence only; whole-set and phase constraints use full-file durations.
          Inspect the existing cues for each exact file, audition it yourself, and
          supply explicit entry/exit seconds with its indexed content hash.
          Mark reviewed only after your own review. Specify each adjacent overlap,
          including zero for an intentional cut. Missing evidence leaves mixed elapsed time unavailable.
    
        
        
    Opt-in planning excludes files without valid reviewed windows and requires
          an explicit valid overlap for every selected transition. Phase boundaries
          begin at the incoming track; overlap time is charged to the outgoing phase.
          Estimates do not certify sound, safety or actual playback.
